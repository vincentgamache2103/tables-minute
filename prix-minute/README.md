# Prix minute

Version d'essai : scanne un produit à l'épicerie et vois si le spécial est un vrai bon prix, d'après l'historique des prix au Québec.

- Site : https://vincentgamache2103.github.io/tables-minute/prix-minute/ (dossier temporaire dans le dépôt de Tables minute)
- Statistiques : prixminute.goatcounter.com (sans identifiant ni témoin)
- Formulaires : Web3Forms (prix vus en magasin, avis)
- Lecture des codes-barres : Quagga2 1.8.4 (licence MIT), chargé de jsDelivr avec une empreinte SRI, décodé dans le navigateur
- Noms de produits : Open Food Facts

Projet indépendant, sans lien avec aucun épicier.
